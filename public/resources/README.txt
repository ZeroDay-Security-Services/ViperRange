ViperRange Lab Resources
ZeroDay Security Services

This directory holds downloadable artifacts (binaries, ciphertext files,
archives, audio, etc.) referenced by offline-challenge labs. Populate
each resource path referenced in prisma/seed.ts with the corresponding
generated artifact before deploying to production. Artifact generation
scripts are not included in this repository snapshot — each offline lab's
walkthrough documents the exact structure and content each resource file
must contain so it can be regenerated deterministically.
